# Installation Guide

## Option 1: Run with Python (Source)

1. Clone the repository:
   ```bash
   git clone https://github.com/Sopwit/PopUp-App.git
   cd PopUp-App
   ```

2. (Optional) Create and activate a virtual environment:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Launch the application:
   ```bash
   make run
   # Or directly:
   python3 -m popupapp
   ```

## Option 2: Precompiled Binaries

Download the latest precompiled standalone binary for Linux from the [GitHub Releases](https://github.com/Sopwit/PopUp-App/releases) page.
